# Data Cleaning & Preprocessing using Titanic Dataset

## 📌 Objective

The objective of this project is to learn how to clean and preprocess raw data before applying Machine Learning algorithms.

## 🛠 Tools & Libraries Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## 📂 Dataset

Used the Titanic Dataset for preprocessing and cleaning tasks.

Dataset Source:
https://www.kaggle.com/c/titanic/data

## 🔍 Tasks Performed

1. Imported and explored the dataset.
2. Checked missing values and data types.
3. Handled missing values using median and mode.
4. Removed unnecessary columns.
5. Converted categorical data into numerical format using encoding.
6. Standardized numerical features.
7. Visualized outliers using boxplots.
8. Removed outliers using the IQR method.
9. Saved the cleaned dataset.

## 📊 Output

* Cleaned and preprocessed dataset ready for Machine Learning.
* Outliers removed.
* Missing values handled successfully.

## 📁 Files Included

* Titanic_Dataset.csv
* cleaned_titanic.csv
* Task 1.ipynb

## 🚀 Conclusion

This project helped understand the importance of data preprocessing in Machine Learning workflows. Clean and structured data improves model performance and accuracy.
